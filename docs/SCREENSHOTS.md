# Filspresso Page Screenshot Manifest

This manifest reflects the current PNG files in `docs/screenshots` and what each image should communicate.

## Screenshot Files And Purpose

- `home.png`: Main landing page with hero, primary navigation, and top call-to-actions.
- `coffee.png`: Coffee product catalog with product cards and buying entry points.
- `coffee_types.png`: Coffee-type segmentation and browse refinement state.
- `capsule_amount.png`: Quantity or capsule amount selection UI.
- `machines.png`: Machine catalog and machine discovery interface.
- `account_machines.png`: Account-level machine management area.
- `favorites.png`: Saved/favorited product list.
- `shopping_bag.png`: Cart summary before checkout.
- `payment_page.png`: Payment and order finalization step.
- `orders.png`: Order history and order tracking page.
- `subscription.png`: Subscription enrollment/configuration view.
- `subscription_account.png`: Subscription management inside account context.
- `management_account.png`: General account management dashboard.
- `member_status_1.png`: Membership status state variant 1.
- `member_status_2.png`: Membership status state variant 2.
- `spending_analytics.png`: Spending analytics and user insights page.
- `graphs.png`: Data visualization/chart-focused view.
- `admin_page.png`: Administrative dashboard for privileged actions.
- `services.png`: Services and support information page.
- `maintenance.png`: Maintenance/service workflow page.
- `warranty_repair.png`: Warranty and repair policy/request page.
- `kafelot.png`: Kafelot AI assistant interface.
- `kafelot_policy.png`: Kafelot privacy policy page.
- `privacy_policy.png`: Global platform privacy policy.
- `terms_of_use.png`: Terms of use page.
- `sales_and_refunds.png`: Sales and refunds legal/policy page.

## Recommended Capture Settings

- Desktop: 1920x1080
- Mobile: 390x844
- Format: PNG
- Keep browser chrome out of frame
- Capture fully loaded states (avoid skeleton/loading states)
